# 🧬 Neuro-Synthetix: Autonomous Drug-Target Discovery

**30-Day MLOps Challenge | From Chemical Engineering to AI Science**

Neuro-Synthetix is a modular platform designed to accelerate drug discovery using **Graph Neural Networks (GNNs)**. The system predicts the **binding affinity** between protein targets and chemical compounds, validating predictions through **physics-based molecular docking**.
